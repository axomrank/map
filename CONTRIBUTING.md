# Contributing

Use [the collection plan](docs/COLLECTION_PLAN.md) to choose a gap, then follow [the development guide](docs/DEVELOPMENT.md).

Every addition should include a publisher/source URL, date or an explicit unknown value, geographic scope, original CRS, accuracy/scale if available, reuse terms, and required attribution. Preserve originals and document transformations. Keep historical and current boundaries separate; join demographic tables by dated official codes rather than name alone.

For place records, retain original names and add Assamese/English names as separate fields when verified. Never guess coordinates or administrative membership. Mark uncertain observations and include collection method and verification status.

Before submitting: rebuild exports, run validation and tests, inspect representative features on a map, and check license/attribution completeness. In the PR, list counts, source/version, affected themes, and known gaps. Do not include credentials or personal contact/ownership records in map contributions.
