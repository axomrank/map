# Map formats and conversion policy

The archive keeps originals and makes three derived exports for every supplied dataset. `catalog/datasets.json` is the canonical machine-readable catalog; `catalog/datasets.csv` is its spreadsheet-friendly summary.

| Format | Use | Limits |
| --- | --- | --- |
| KML/KMZ | Google Earth; original styling, folders, altitude settings | Large XML; limited web rendering |
| GeoJSON | Leaflet, web maps, QGIS, data exchange | Text can be large; styling is application-specific |
| CSV | Search, inventory, spreadsheet joins | Geometry is JSON in a column; not a stand-alone shapefile |
| GeoPackage, optional | QGIS analysis, multiple layers, spatial indexes | Requires GDAL/QGIS; not generated by the standard-library pipeline |
| Shapefile ZIP, optional | Legacy GIS exchange | Field truncation, encoding limits, separate geometry types; multiple component files |
| GeoTIFF / COG, future sources | Imagery, elevation, rainfall, land cover | Requires raster processing; never convert point/polygon KML into an invented raster |
| MBTiles / PMTiles, future builds | Offline/vector-tile delivery | Derived visualization, retain full-resolution source separately |
| PDF / SVG / PNG, future maps | Print, presentations, historical scans | Images/PDF are not georeferenced vector boundaries |

The converter keeps longitude, latitude and any supplied third coordinate. KML altitude modes and terrain clamping have no direct GeoJSON equivalent; use the original KML for those semantics. It closes unclosed polygon rings but does not simplify, deduplicate, clip, repair topology, or change coordinates. Inner rings are retained. Mixed KML `MultiGeometry` becomes GeoJSON `GeometryCollection` to avoid discarding points paired with village polygons.

Feature IDs are deterministic for a given source order, not official place IDs. Structured ExtendedData and attributes embedded in description `<br>` fields are preserved separately. HTML descriptions remain in downloads for fidelity; web popups display only plain text. Unsupported tracks, models, network links, and overlays fail the build rather than silently dropping spatial content.

For optional GIS exports, open `map.geojson` in QGIS and use **Export → Save Features As → GeoPackage**. Split mixed geometry by type before exporting to Shapefile. Record the export command or settings, CRS, source checksum, and tools/version. With GDAL installed:

```bash
ogr2ogr -f GPKG assam-temples.gpkg data/derived/heritage/assam-temples/map.geojson -nln temples
```

Validate polygon topology with QGIS **Check validity** before analytical use. Save any repaired geometries as a separate derived dataset with a repair report; retain the original.
